<<<PLAN section="state">>>
- messages: MessagesState — the support conversation; no extra domain state is needed

<<<PLAN section="graph">>>
- agent (llm) reads the thread and either answers or calls a tool
- tools runs the requested tool and returns to agent
- agent ends the run once it has an answer
<<<ENDPLAN>>>
<<<PLAN section="notes">>>
- pg_query is read-only and takes a static SQL string; order filters are passed as arguments, not interpolated.
- Nothing is emailed — this agent answers in the conversation only.
